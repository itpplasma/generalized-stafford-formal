# Generalized Stafford: Theorem A

A Lean 4 and Mathlib formalization of an affine generation theorem for simple
Noetherian rings with infinite centre, and of its module corollaries. The
case `a = 1`, `B = 0` of Theorem A is the identity `R = dR + HdR`, which
Stafford conjectured for the Weyl algebras (Conjecture 3.8 of Stafford 1978).

Status: all 14 challenge theorems are proved and accepted in a local replay of the Palomar check (Comparator with NanoDa and the Lean kernel; Landrun in best-effort mode); not registered on Palomar. Independent human review is pending.

## The theorem

Let `R` be a ring. Modules are right modules, "finite" means finitely
generated, and products are read in the order written. An element is
*regular* if it is a left and right non-zero-divisor. `Kdim` is the right
Gabriel-Rentschler (deviation) dimension, not the classical Krull dimension
of prime chains. A module is *Goldie-torsion* if each element is killed by a
regular element. The hypotheses are:

| Name | Statement |
| --- | --- |
| (S) | `R` is simple |
| (N) | `R` is right Noetherian |
| (Z) | the centre of `R` is infinite |
| (H_all) | `Kdim(R/dR)` is finite for every regular `d` |
| (H_omega) | `Kdim R <= omega` |

Under (S) the centre is a field, so (Z) says that `R` is an algebra over an
infinite central field.

**Theorem A' (fixed ideal).** Assume (S), (N), (Z). Let `I` be a right ideal
that contains a regular element and has `Kdim(R/I)` finite. For every `x` and
every nonzero `t` in `R` there is `H` with

```text
I + (x + H t) R = R.
```

**Theorem A (fixed anchor).** Assume (S), (N), (Z). Let `d` be regular with
`Kdim(R/dR)` finite. For every nonzero `a` (possibly a zero-divisor) and every
`B` there are `H, U, V` with

```text
1 = d U + (B + H a) d V.
```

**Corollary B.** If `R` is right Noetherian with `Kdim R <= omega`, then
`Kdim(R/I)` is finite for every right ideal `I` containing a regular element.
Hence, under (S), (N), (Z), Theorem A holds for every regular `d` and
Theorem A' for every such `I`.

**Corollary C.** Assume (S), (N), (Z).

- (C.1) If `M` is a finite Goldie-torsion module with `Kdim M` finite, then for
  every `x` in `M` and nonzero `t` in `R` there is `h` in `M` with
  `M = (x + h t) R`. Under (H_all), in particular under (H_omega), the
  dimension hypothesis holds for every finite Goldie-torsion `M`. Stable form:
  if `c, u` are Goldie-torsion and `Kdim(uR)` is finite, then
  `cR + uR = (c + u H t) R` for some `H`.
- (C.2) Under (H_all) every right ideal `I` is generated by two elements. More
  precisely, if `a` in `I` satisfies `aQ = IQ` (`Q` the classical right
  quotient ring), then for every `y` in `I` and nonzero `t` there is `h` in `I`
  with `I = aR + (y + h t) R`.
- (C.3) Under (H_all), for every finite module `M`,
  `ceil(rho M) <= mu(M) <= floor(rho M) + 1`, where `mu` is the minimal number
  of generators and `rho(M) = length_Q(M ⊗_R Q) / s` for `Q = M_s(D)`. The
  lower bound needs only (S), (N).

## What is formalized

- Library `GeneralizedStafford`: Theorem A' (`fixed_ideal`), Theorem A
  (`fixed_anchor`), Corollary B (`quotient_finite_of_omega`,
  `fixed_ideal_of_devLE_omega`, `fixed_anchor_of_devLE_omega`) and
  Corollary C (`span_pair_eq_span_affine`, `prescribed_cyclic*`,
  `two_generated*` and the C.3 bounds). The library endpoints are listed in
  [docs/endpoints.txt](docs/endpoints.txt).
- Palomar challenge: `GeneralizedStaffordChallenge.lean` (identical copy
  `Challenge.lean`) states the 14 compared theorems with Mathlib-only
  definitions. `GeneralizedStaffordSolution.lean` (identical copy
  `Solution.lean`) proves them by transport from the library and does not
  import the challenge. `comparator.json` lists the theorems.

The challenge encodes C.3 without division or rounding, through uniform
dimensions: `s = udim(R_R)` and `length_Q(M ⊗_R Q) = udim(M/t(M))`. These two
classical identities (Goldie theory) connect the Lean statements to `rho`.

The project declares no axioms. The only `sorry`s are the 14 deliberate
placeholders in each challenge file. The endpoints depend only on `propext`,
`Classical.choice` and `Quot.sound`.

Not formalized: the ordinal refinement `delta(d) < Kdim R` in the dimension
part of Corollary B, opposite-side statements, and results beyond `omega`,
applications and examples.

## Proof structure

Theorem A' is proved by a two-call descent on `Kdim(R/I)`: each step replaces
the affine generator `x + H t` by one whose quotient `R/(I + fR)` has strictly
smaller deviation, using Goldie's theorem and a good nonzero central scalar.
Theorem A follows from Theorem A' with `I = dR`, `x = B d` and `t = a d`. The
corollaries are proved in their own files, and each corollary file opens with a
short account of its proof. The upper bound of C.3 is proved by induction on
the number of generators `q`, without transferring the module to a matrix ring.

## Building and checking

Requires [elan](https://github.com/leanprover/elan) and Python 3.11 or later.
The pins are Lean `leanprover/lean4:v4.35.0-rc3` (`lean-toolchain`) and, in
`lakefile.toml`, Mathlib and
[AlgebraicAnalysis](https://github.com/itpplasma/algebraic-analysis).

```sh
lake exe cache get
lake build
scripts/verify.sh                   # pins, build, endpoint axiom audit
scripts/bootstrap-palomar-tools.sh  # once: Comparator, lean4export, NanoDa, Landrun
scripts/verify-palomar.sh           # Palomar comparison of challenge and solution
```

Do not run `lake update`; it moves the pins. See
[docs/building.md](docs/building.md).
